# نظام استطلاع رأي موظفي مجموعة كيان للهندسة والتجارة

نظام متكامل وخفيف لاستطلاع رأي الموظفين (74 موظفاً) مع ضمان الخصوصية والسرية التامة بنسبة 100%، جاهز للرفع المباشر على منصة **Vercel** مع قاعدة بيانات سحابية مجانية (**Upstash Redis / Vercel KV**).

---

## 🚀 المميزات الرئيسية

1. **واجهة الموظفين (`/` أو `/survey`):**
   - تصميم أنيق وسريع جداً ومتوافق مع الهواتف الذكية.
   - 6 أسئلة استراتيجية تغطي الراحة، التواصل، العقبات، الدعم، الأفكار، والانتقادات.
   - حفظ الردود بدون أسماء أو أرقام تعريفية أو بصمات رقمية.
   - منع تكرار الإرسال بالخطأ بعد الانتهاء.
   - إشعار إغلاق أنيق في حال انتهاء فترة الاستطلاع.

2. **لوحة تحكم المسؤول (`/admin`):**
   - محمية بكلمة مرور مشفرة.
   - إحصائيات فورية (عدد الردود، نسبة المشاركة من 74 موظف، متوسط تقييم الدعم).
   - رسوم بيانية تفاعلية لنتائج الأسئلة.
   - فلترة وبحث حي داخل جميع الملاحظات والأفكار والانتقادات.
   - **لوحة تحكم بالحالة والمواعيد:**
     - فتح أو إغلاق الاستطلاع يدوياً بنقرة واحدة.
     - تحديد موعد وتاريخ للإغلاق التلقائي (`Auto-close Deadline`).
     - زر سريع لنسخ رابط الاستطلاع لمشاركته مع الموظفين.
   - تصدير جميع النتائج بنقرة واحدة إلى ملف Excel/CSV يدعم اللغة العربية (`UTF-8 BOM`).

3. **البنية الخلفية (`/api` Serverless Functions):**
   - `/api/submit`: استقبال الردود وتنظيفها وحفظها مع فحص حالة الاستطلاع.
   - `/api/results`: جلب النتائج مع خلطها عشوائياً وتجريد الطوابع الزمنية لحماية سرية الموظفين.
   - `/api/status`: فحص حالة الاستطلاع (مفتوح/مغلق).
   - `/api/settings`: إدارة موعد الانتهاء وحالة الفتح والإغلاق للمسؤول.

## 📋 خطوات الرفع على Vercel (خلال دقيقتين)

### الخطوة 1: رفع المشروع على Vercel

#### الطريقة الأولى (الأسهل عبر GitHub):
1. ارفع هذا المجلد إلى حسابك في **GitHub** في مستودع جديد (Repository).
2. افتح [Vercel Dashboard](https://vercel.com/dashboard) واضغط **"Add New Project"**.
3. اختر المستودع واضغط **"Deploy"**.

#### الطريقة الثانية (عبر موجه الأوامر Vercel CLI):
في نفس مجلد المشروع، نفّذ:
```bash
npx vercel
```
واتبع التعليمات البسيطة التي تظهر لك في الشاشة.

---

### الخطوة 2: ربط قاعدة البيانات المجانية (Upstash Redis)

1. بعد إنشاء المشروع في لوحة تحكم Vercel، اذهب إلى تبويب **"Storage"** من شريط المشروع العلوي.
2. اضغط **"Create Database"** واختر **"Upstash Redis"** (أو Vercel KV).
3. اختر خطة **Free Tier (مجانية)** واضغط **"Create"**.
4. اضغط **"Connect"** لربط قاعدة البيانات بالمشروع (`Connect to Project`).
5. بمجرد الربط، سيقوم Vercel تلقائياً بحقن المتغيرات (`UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN`).

> **ملاحظة:** النظام يدعم كلاً من `UPSTASH_REDIS_*` و `KV_REST_API_*` تلقائياً بدون أي تعديل برمجي.

---

### الخطوة 3: تحديد كلمة مرور لوحة التحكم (اختياري)

كلمة المرور الافتراضية للوحة المسؤول هي:
```
Kayan1234
```
إذا أردت تغييرها:
1. في صفحة مشروعك على Vercel، ادخل إلى **Settings** ➔ **Environment Variables**.
2. أضف متغيراً جديداً باسم:
   - **Key**: `ADMIN_PASSWORD`
   - **Value**: `كلمة_المرور_الجديدة_التي_تريدها`
3. اضغط **Save**، ثم اذهب إلى **Deployments** واضغط **Redeploy**.

## 🛠️ الاختبار المحلي (Local Development)

إذا أردت تجربة المشروع محلياً على جهازك:
```bash
npm install
npm run dev
```
أو افتح مباشرة ملف `survey.html` وملف `admin.html` في متصفحك.
النظام مزود بنظام ذاكرة احتياطي (In-Memory Mock) يعمل محلياً حتى قبل ربط قاعدة البيانات السحابية.
